# Tasks

## Conventions

- Task lines should use Markdown checklist format: `- [ ] Task description`
- Put assignees at the end of the task line in this format: `[@handle]`
- Omit the assignee segment if the task is unassigned
- Keep task text stable when possible so reassignment is easy to track
- Use short section headers to group work by feature or area
